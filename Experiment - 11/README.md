# Experiment 11: Display Google Maps in Android

## 📌 Experiment Title
**Develop an Android application to display a map using the Google Maps API.**

## 🎯 Aim
To develop an Android application that integrates Google Maps API to display a map within the application.

## 🛠️ Technologies Used
- Android Studio
- Kotlin
- XML
- Google Maps SDK for Android
- Google Maps API
- Android SDK

## 📱 Application Overview
This application demonstrates the integration of Google Maps into an Android application. It allows users to view a map interface and explore geographical locations.

## ✨ Features
- **Google Maps Integration:** Displays Google Maps inside the application.
- **Map Navigation:** Allows users to move around the map.
- **Zoom Controls:** Supports zooming in and out to explore locations.
- **Location Display:** Displays geographical areas through the map interface.
- **Interactive Map:** Supports basic map interaction.

## ⚙️ Implementation Steps
1. Create a new Android project in Android Studio.
2. Configure the Google Maps SDK for Android.
3. Obtain and configure a Google Maps API key.
4. Add the required dependencies and permissions.
5. Integrate a map using `SupportMapFragment` or `GoogleMap`.
6. Configure the map in the activity.
7. Run the application and verify that Google Maps is displayed.

## 🧩 Main Components

| Component | Purpose |
|---|---|
| `MainActivity.kt` | Handles application logic |
| `activity_main.xml` | Defines the application layout |
| `SupportMapFragment` | Displays the map within the activity |
| `GoogleMap` | Provides map interaction and configuration |
| Google Maps API Key | Authorizes access to the Maps SDK |

## 🔑 Configuration
A valid Google Maps API key is required. Enable the **Maps SDK for Android** in the Google Cloud project and configure the key securely according to Google's documentation.
